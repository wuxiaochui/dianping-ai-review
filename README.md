# 点评 AI · 评价生成器

一个纯前端、本地优先的点评写作辅助工具。导入自己的历史评价作为语料，让 AI 学习你的行文习惯，再按商家类型、星级和场景生成自然、不像模板的评价。

无需后端、无需构建，所有数据保存在浏览器 `LocalStorage` 中，AI 能力通过兼容 OpenAI Chat Completions 协议的接口接入。

## 功能特性

### 语录库
- 按标签组管理历史评价语料，内置真实日常风、夸张种草风、文艺细腻风、吐槽避雷风等预设风格
- 支持批量导入、逐条编辑、按标签筛选与检索
- 语料会作为 AI 的风格参考，训练结果与语料相互独立

### 训练
- 逐条调用 AI 深度分析语料，提炼语言习惯、句式特征与格式偏好
- 自动识别品类，无需手动选择分类
- 展示分析进度与分类置信度，单条失败不影响整体流程
- 训练结果实时保存，刷新或关闭页面后可继续

### 生成评价
- 三种模式：直接生成、AI 提问、文本润色
- 星级可选 0–5 星（含无评分），支持精确字数或短 / 中 / 长预设
- 支持多选式提问，选项逐行展示，并保留「其他（请补充）」输入入口
- 流式输出，可随时中断；润色模式提供原文与结果的对比视图
- 生成结果一键复制，自动记录到历史

### 历史
- 按时间与模式筛选历史记录，支持再次使用与删除
- 可导出为文本，便于归档

### 设置
- 多个 AI 服务商配置与切换，支持连通性测试与超时设置
- 数据导入 / 导出，用于换机迁移或备份
- 主题（浅色 / 深色 / 跟随系统）与多语言切换

### 其他
- 5 种界面语言：简体中文、繁體中文、English、한국어、Français
- 移动端优先的响应式布局，适配桌面与手机浏览器
- AI 训练过程配有 Lottie 动效反馈

## 技术栈

- 原生 HTML / CSS / JavaScript（ES5 语法，无框架、无打包）
- `LocalStorage` 本地持久化
- 兼容 OpenAI 协议的 Chat Completions 接口（流式 SSE）
- Lottie Web 播放训练动效

## 快速开始

项目是纯静态页面，选择任意一种方式启动：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node
npx serve .
```

然后访问 `http://localhost:8080`。

不建议直接双击 `index.html` 以 `file://` 方式打开，部分浏览器会限制跨域请求与本地存储。

## 配置 AI

1. 进入「设置」，选择或新增服务商
2. 填写 `Base URL`、`API Key`、模型名称，例如：

| 服务商 | Base URL | 模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

3. 点击「测试连接」，成功后即可在训练与生成中使用

API Key 只保存在当前浏览器的 `LocalStorage` 中，不会上传到任何第三方服务器；但页面会直接向你所配置的服务商发起请求，请注意浏览器环境的可信度。

## 数据与隐私

- 所有语料、训练结果、历史记录均存储于浏览器本地
- 换设备时可在「设置」中导出数据包，再到新设备导入
- 清除浏览器站点数据会丢失本地内容，建议定期导出备份
